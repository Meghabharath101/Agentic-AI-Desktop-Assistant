# Agentic AI Desktop Assistant

An AI-powered desktop assistant developed using Python, Ollama and Streamlit.

## Features
- AI Chat
- Voice Interaction
- Open Applications
- File Management
- Email Writing
- Web Search
- WhatsApp Integration
- Command Execution

## Technologies Used
- Python
- Ollama
- Streamlit
- Speech Recognition

## How to Run

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python -m streamlit run ui_app.py
```
